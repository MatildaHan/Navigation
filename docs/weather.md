# 可选天气效果

效果完全位于 `assets/js/weather.js` 和 `assets/css/weather.css`，不依赖首页配置解析器、卡片、播放器或外部动画库。

- 右上角只显示当前天气图标和循环切换图标，点击按钮按 **晴 → 雨 → 雪 → 落叶 → 关闭 → 晴** 切换。按钮提示和无障碍标签说明当前模式及下一个模式，支持 Enter 和空格。
- 晴天光束从右上方同一光源向左下扇形发散，两侧柔化并随距离衰减，伴有浮尘；雨天有雨丝和飞溅；雪天为摇摆雪花；落叶带旋转和翻动。粒子沿右上到左下的方向移动。
- 默认雨天；系统选择“减少动态效果”时默认关闭，仍可手动选择。旧雨效的关闭偏好会保留。
- 雾天模式已移除，旧的雾天选择会恢复为关闭。
- 选择保存在当前浏览器的 `navigation-weather-mode` 项中；存储不可用时仍可切换，但刷新后恢复默认值。无需位置权限、天气 API 或网络请求。
- 关闭时停止绘制；切换到后台时暂停动画。画布不接收点击、触摸或键盘输入，不改变个人记录。
- 雨滴在主面板、侧边栏和底部导航栏顶边或窗口底部产生飞溅。

## 完整移除

1. 删除 `index.html` 中引用 `assets/css/weather.css` 的 `<link>` 和引用 `assets/js/weather.js` 的 `<script>`，以及天气效果注释。
2. 删除这两个独立文件、`tests/weather.test.js` 和本说明文件。

无需修改 `script.js`、`style.css`、`config.md` 或任何卡片代码。浏览器里留下的天气偏好不会影响其余功能。
