# 可选雨效

雨效完全位于 `assets/js/rain.js` 和 `assets/css/rain.css`，不依赖首页配置解析器、卡片、播放器或外部库。

- 页面角落的“雨效”开关可随时开启或关闭，关闭后停止绘制。
- 默认开启；系统选择“减少动态效果”时默认关闭，仍可手动开启。
- 选择保存在当前浏览器的 `navigation-rain-enabled` 项中；存储不可用时仍可切换，但刷新后恢复默认值。
- 手机上的开关位于右上角，仅显示拨钮，保留“雨效”无障碍标签；画布不接收点击、触摸或键盘输入。
- 雨滴在主面板、侧边栏和底部导航栏顶边或窗口底部产生飞溅；切换到后台时暂停动画。

## 完整移除

1. 删除 `index.html` 中引用 `assets/css/rain.css` 的 `<link>` 和引用 `assets/js/rain.js` 的 `<script>`，以及雨效注释。
2. 删除这两个独立文件、`tests/rain.test.js` 和本说明文件。

无需修改 `script.js`、`style.css`、`config.md` 或任何卡片代码。浏览器里留下的开关偏好不会影响其余功能。
