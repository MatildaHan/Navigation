# 卡片配置

全局配置在根目录 `config.md`。每个卡片的配置独立读取，保存后刷新页面即可。通过 HTTP 服务器预览，图片和音频路径始终相对于网站根目录。

| 文件 | 分区 | 内容 |
| --- | --- | --- |
| `greeting.md` | `greetings` | 招呼卡片副标题 |
| `calendar.md` | `calendar`、`todos` | 日历标题和按日期显示的待办 |
| `quote.md` | `quote`、`quotes` | 首页格言和详情中的更多格言 |
| `music.md` | `playlist` | 歌曲、音频、封面和说明 |
| `anniversary.md` | `anniversary` | 事件、日期、类型、重复和说明 |
| `books.md` | `books` | 书名、作者、状态、进度、封面和说明 |
| `movies.md` | `movies` | 片名、类型、评分、状态、封面和说明 |

保留 `--- 分区名 ---` 标记，以「键：值」写字段，每个条目用空行分隔。以 `#` 开头的行不会显示。说明写在单行，内容作为纯文本安全显示。

日历待办示例（将条目放在 `calendar.md` 的 `--- todos ---` 下面）：

```text
日期：2026-10-08
内容：阅读一章书
时间：20:00
状态：待办
说明：完成后将状态改为已完成。
```

日期必须为 `YYYY-MM-DD`。详情页选择日期后显示当天待办，有记录的日期显示圆点；待办内容和状态通过 Markdown 维护。

`quote` 是首页展示的一则格言；`quotes` 是详情页额外展示的列表。两者支持「格言」「作者」「出处」「说明」。书架进度使用 `45%` 形式，纪念日类型为「已过日」或「倒数日」，重复可填「每年」。

详情地址为 `#calendar`、`#quote`、`#music`、`#anniversary`、`#books`、`#movies`，可直接打开、刷新或使用浏览器前进后退。音乐详情与首页共用同一个播放器，切换视图时保持播放。

为兼容旧配置，模块文件读取失败或未提供某分区时，会保留 `config.md` 中相应的旧分区内容，并提示读取失败。模块文件中的同名分区优先。
