# 卡片配置

全局配置在根目录 `config.md`。每个卡片的配置独立读取，保存后刷新页面即可。通过 HTTP 服务器预览，图片和音频路径始终相对于网站根目录。

| 文件 | 分区 | 内容 |
| --- | --- | --- |
| `greeting.md` | `greetings` | 招呼卡片副标题 |
| `calendar.md` | `calendar`、`todos` | 日历标题和按日期显示的待办 |
| `quote.md` | `quote`、`quotes` | 首页格言和详情中的更多格言 |
| `music.md` | `playlist` | 歌曲、音频、封面、歌手、说明与歌词文件 |
| `anniversary.md` | `anniversary` | 事件、日期、类型、重复和说明 |
| `books.md` | `books` | 书名、作者、状态、进度、封面和说明 |
| `movies.md` | `movies` | 片名、类型、评分、状态、封面和说明 |
| `tools.md` | `tools` | 外部工具与本地工具标识、名称、分类、网址和说明 |
| `games.md` | `games` | 游戏标识、名称、分类与操作说明 |
| `checkin.md` | `checkins` | 打卡标识、名称和说明 |
| `habits.md` | `habits` | 习惯标识、名称、每周目标和说明 |
| `focus.md` | `focus` | 专注分钟、休息分钟 |
| `notes.md` | `notes` | 标识、内容、标签、日期；初始的只读摘录 |
| `projects.md` | `projects`、`steps` | 项目与阶段步骤 |
| `wishlist.md` | `wishlist` | 愿望标识、名称、分类、日期、说明和状态 |

保留 `--- 分区名 ---` 标记，以「键：值」写字段，每个条目用空行分隔。以 `#` 开头的行不会显示。说明写在单行，内容作为纯文本安全显示。

日历待办示例（将条目放在 `calendar.md` 的 `--- todos ---` 下面）：

```text
日期：2026-10-08
内容：阅读一章书
时间：20:00
状态：待办
说明：完成后将状态改为已完成。
```

日期必须为 `YYYY-MM-DD`。详情页选择日期后显示当天待办，有记录的日期显示圆点；待办内容和状态通过 Markdown 维护。

`quote` 是首页展示的一则格言；`quotes` 是详情页额外展示的列表。两者支持「格言」「作者」「出处」「说明」。书架进度使用 `45%` 形式，纪念日类型为「已过日」或「倒数日」，重复可填「每年」。

详情地址为 `#calendar`、`#quote`、`#music`、`#anniversary`、`#books`、`#movies`，可直接打开、刷新或使用浏览器前进后退。音乐详情与首页共用同一个播放器，切换视图时保持播放。

为兼容旧配置，模块文件读取失败或未提供某分区时，会保留 `config.md` 中相应的旧分区内容，并提示读取失败。模块文件中的同名分区优先。

## 三页内容

第一页保留原有招呼、日历、格言、音乐、纪念日、书架和观影卡片。第二页地址是 `#life`，展示工具箱、今日打卡、习惯养成、专注计时、随手记、目标与项目、愿望清单，以及答案之书、赛博木鱼、英语学习、日语学习、古诗词背诵、历史事件、本地音乐七张独立工具卡片。第三页 `#games` 展示十个本地游戏。三页共用相同的面板高度，面板按屏幕高度适配；生活和游戏卡片在面板内部纵向滚动，卡片文字自动换行，外层页面保持固定。支持触屏横向滑动、触控板横向滚动、鼠标拖动、分页链接，以及网格内左右方向键；手机端也在面板内部滚动查看内容。

新详情地址为 `#tools`、`#checkin`、`#habits`、`#focus`、`#notes`、`#projects`、`#wishlist`，返回后回到第二页。原有详情返回第一页。所有详情支持直接打开和浏览器历史导航。

## 配置与个人记录

新增列表的「标识」使用 1～64 位英文字母、数字、下划线或短横线，在同一分区内唯一，修改名称时保留标识。打卡和习惯使用相同标识时共用完成记录。每周目标为 1～7 天；每周从周一开始，统计本周完成天数。过去 28 天的热力图可点击进入对应日期补打卡，未来日期不能打卡。

`projects` 的标识由 `steps` 的「项目」字段关联，每一步也有独立标识和「内容」，可选「状态：已完成」。愿望清单也支持初始「状态：已完成」。示例项目和习惯可直接在 MD 中替换为自己的内容。

MD 定义公开内容、项目和目标。打卡、备注、工具收藏、专注历史、随手记、步骤完成和愿望状态保存在当前浏览器当前站点的 `navigation-life-v1` 中，不写回 MD。不同浏览器或网站域名之间独立；访客会看到自己的记录，不会修改站点作者的记录。新建随手记可编辑，移到回收站后可恢复，MD 配置的初始摘录通过文件修改。

在打卡详情点击「导出记录」，生成可下载的 JSON 备份，同时可以查看和复制备份内容。「导入记录」先校验版本、数据类型、日期、标识和文件大小，成功后替换当前本地记录，并保存导入前数据；「恢复导入前记录」恢复最近一次导入前的记录。本地记录及导入文件最多 2 MB，保证导出的备份仍可导入。导入和恢复会停止计时，配置文件不随记录备份迁移。

专注和休息各为 1～180 分钟，按真实截止时间计算，暂停、刷新和切页保留计时；一轮专注完成只计入一次历史，随后等待手动开始休息。重置或切换模式会取消当前未完成的一轮。开始后调整 MD 的时长不会更改已运行的这一轮。

## 验证

运行 `node --check assets/js/script.js`、`node --check assets/js/life.js` 和 `node --test tests/*.test.js`。浏览器检查三页切换、各详情、手机布局、记录交互和播放连续性；本项目不需要包管理或构建工具。

## 本地工具与游戏

`tools.md` 同时维护外部工具链接和本地工具卡片。工具箱的计数、搜索、分类与收藏只包含外部工具；本地工具使用 `#tool/标识` 地址，在生活页中以独立卡片打开。本地工具包括 `book`、`cyber-muyu`、`english-study`、`japanese-study`、`poetry-recite`、`history-events`、`music-player`。它们在当前页面打开，返回生活与工具。

`games.md` 中的标识对应 `Games-main/games/` 中的文件名：`tetris`、`sudoku`、`nonogram`、`chess`、`gomoku`、`klotski`、`minesweeper`、`lightsout`、`graphcoloring`、`zebra`。详情地址使用 `#game/标识`，返回第三页。工具和游戏共用固定外壳，支持顶部选择器切换、深链接刷新与浏览器前进后退。游戏键盘操作可先点击游戏区域或「键盘操作」按钮。

入口名称、分类与说明由 MD 配置，允许嵌入的本地文件在 `assets/js/apps.js` 中明确列出；新增实现时需同时更新清单。旧 `Games-main/index.html` 和 `Tools-main/index.html` 会转到主页相应入口；直接打开单个 HTML 时也有返回链接。通用外观在 `assets/css/apps.css` 中，保留棋盘必要的对比色。象棋规则和 AI 引擎在 `Games-main/js/chess-engine.js`，AI 在 Worker 中限时搜索。

本地音乐使用浏览器文件选择器，不上传音频，离开工具会停止播放并释放资源。语音朗读依赖浏览器及系统安装的语音；没有对应语音时可能无法发音。木鱼次数、俄罗斯方块最高分、数独解锁记录分别使用原有键 `muyu.count`、`tetrisBest`、`sudokuProgress`，独立于生活记录 JSON 的导入导出。木鱼归零支持当次页面内撤销。切换游戏会开始新局，后台时俄罗斯方块暂停，象棋停止搜索。

运行 `node --test tests/*.test.js` 检查生活记录、配置、游戏规则与题库；浏览器中仍须验证实际操作与响应布局。

## 音乐详情

`#music` 使用深色黑胶播放器，播放时唱片旋转，提供歌词和歌单切换、进度拖动、音量、静音、列表／单曲循环与喜欢功能。首页与详情共用同一个音频节点，切页保持歌曲与播放进度；减少动态效果的系统设置会关闭唱片旋转。

`playlist` 条目可选填「歌手」（兼容「艺术家」）和「歌词」。歌词为相对于网站根目录的 LRC 或纯文本文件路径，也可使用允许浏览器跨域读取的 HTTP(S) 地址。LRC 使用 `[00:12.50]歌词内容` 形式，支持同一句多个时间戳；播放时高亮并滚动到当前歌词，点击歌词可跳转。纯文本只展示内容，不进行时间同步。歌词未配置或读取失败时给出相应提示，音乐仍可播放。现有曲目、封面与音频路径保持兼容。

### 历史事件目录与详情

`history-events.json` 维护历史事件内容，与现有 Markdown 卡片配置独立。`eras` 定义筛选顺序，`sources` 以标识维护资料标题与 HTTPS 地址，`events` 按 `sortYear` 升序排列（公元前年份为负数）。每条事件包含唯一且稳定的 `id`、展示年代 `year`、标题 `title`、时期 `era`、人物 `people`、地点 `place`、简介 `summary`、背景 `background`、经过 `course`、影响 `impact`、阅读提示 `note`、推荐史料 `reading` 和资料标识数组 `sources`。新增事件时须填写全部字段，并区分确切日期、约数与长期进程。

列表直接展示时期筛选与事件卡片，不显示额外标题、介绍或搜索栏；仍兼容早期地址中的关键词参数，点击时期按钮可清除该参数。详情通过工具内部的 `#event/标识` 地址打开；例如独立页面 `Tools-main/tools/history-events.html#event/zhang-qian`。返回目录会保留筛选条件与本次浏览的滚动位置，上一篇／下一篇沿当前筛选结果阅读。首页仍通过 `#tool/history-events` 打开工具；外部阅读资料在新窗口打开。详情不写入个人记录。内容和地址校验可运行 `node --test tests/history-events.test.js`。
